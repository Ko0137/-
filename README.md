# L.I.R.A. (Language Intelligent Robotic Assistant)

L.I.R.A. — умный голосовой и текстовый персональный ассистент, переписанный на React + TypeScript + Vite + Tailwind CSS.

## Основные возможности

- 🎙️ **Голосовой и текстовый ввод**: Распознавание речи через Web Speech API и ввод текста с автоматической озвучкой (TTS).
- 💬 **Интерактивный чат**: Сохранение истории диалогов, временные метки сообщений, фирменные стили реплик LIRA и пользователя.
- 📱 **Запуск приложений и инструментов**: Запуск камеры, веб-браузера, встроенного калькулятора, заметок, будильников, YouTube, карт и других сервисов.
- 🔦 **Управление системой**: Включение/выключение фонарика, мониторинг уровня заряда аккумулятора, управление воспроизведением музыки.
- 📝 **Менеджер заметок**: Сохранение заметок по командам («Заметка...», «Запомни...»), чтение и очистка.
- ⏰ **Умные будильники**: Парсинг времени из команд («Будильник на 7:30», «Разбуди в 8:00») со звуковым оповещением.
- 🎈 **Плавающий виджет**: Плавающая кнопка быстрого вызова L.I.R.A. поверх интерфейса.
- ⚙️ **Настройки и кастомизация**: Настройка имени пользователя, переключение темной/светлой темы, выбор синтеза речи (женский голос LIRA, тихий режим) и добавление собственных пользовательских команд.
- 🔒 **Конфиденциальность**: Все данные обрабатываются и сохраняются исключительно локально на устройстве (localStorage).
